# Principles of Computing — Last Lab

This repository contains a complete LC-3 CPU design implemented in Logisim Evolution. The main `Computer` circuit brings the CPU components together as a complete computer architecture project for the Principles of Computing course.

## Open the project

1. Install or open Logisim Evolution 4.0.0 or later.
2. Open `LC3CPU.circ` in Logisim Evolution.
3. Select the **Computer** circuit to inspect the complete CPU design.

The circuit file identifies its main circuit as `Computer` and was saved for Logisim Evolution 4.0.0.
