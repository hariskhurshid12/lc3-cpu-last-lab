# Principles of Computing — Last Lab

This repository contains the `LC3CPU.circ` circuit project from the Principles of Computing course.

## Open the project

1. Install or open Logisim Evolution 4.0.0 or later.
2. Open `LC3CPU.circ` in Logisim Evolution.
3. Select the **Computer** circuit to inspect the design.

The circuit file identifies its main circuit as `Computer` and was saved for Logisim Evolution 4.0.0.
